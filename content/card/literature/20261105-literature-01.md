**文学院第二十四届学生代表大会 · 学生提案征集**

各位同学：

文学院第二十四届学生代表大会即将召开。为了解同学们的学习、工作、生活情况，反映同学们的合理诉求，提升学习与生活质量，明确学生会未来发展建设目标，本次学代会将**面向全体学生征集学生提案**。

**怎么做**

1. 有意向反映问题的同学，按附件**模板**填写《中国语言文学学院学生代表提案表》（另附一份**填写示例**可参考）；
2. 填好后**交给本班团支书**，由团总支统一打包发送给调研部干事。

**截止时间**

**11 月 8 日（周六）12:00**。

**提案表怎么填（参考示例）**

| 栏目 | 说明 |
| --- | --- |
| 提案人 / 年级 / 联系电话 / QQ | 填本人信息 |
| 附议人（三人以上） | 需三人以上同学联署 |
| 提案类别 | 如「生活服务」「教学管理」等 |
| 案名 | 一句话概括问题 |
| 案由 | 问题是什么、影响如何 |
| 案据 | 具体依据与现状描述 |
| 解决措施 / 建议 | 希望怎么解决 |

示例：案名「天马园区自强打印的回归问题」——案由为原自助打印机存在时打印方便、现较为麻烦；建议「如果能回归尽量回归」。
